# beUI
> Animated components for React and Next.js.
- URL: https://beui.dev
- License: MIT — live-previewable
- Stack: react, nextjs, typescript, tailwind, motion
- Install: `npx shadcn@latest add @beui/<name>`
- Notes: MIT (github.com/starc007/ui-components). Free set only — the 350+ Pro blocks (paid lifetime) and the separate beui-native set are excluded. Docs show bunx --bun shadcn add @beui/<name>; npx works the same. The research quoted 157 free components; the public index (beui.dev/r) lists 122 pages, some of which (button, number, text-animation, not-found…) bundle several registry items that install together. Catalog-only: no vendored previews yet.
- Cataloged in UI Vault: 122 entries
