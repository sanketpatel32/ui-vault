# pdfcn
> Copy-paste PDF components for React, built on Takumi and Forme.
- URL: https://pdfcn.dev
- License: MIT — live-previewable
- Stack: react, typescript, tailwind, takumi, forme
- Install: `npx shadcn@latest add @pdfcn/takumi/<name>`
- Notes: MIT (github.com/shadcn-labs/pdfcn). Prerequisite: a React project running the Takumi (takumi-pdf + @takumi-rs/helpers) or Forme PDF renderer. Forme variants install as @pdfcn/forme/<name>; if the CLI does not resolve @pdfcn, add {"registries": {"@pdfcn": "https://pdfcn.dev/r/{name}.json"}} to components.json. Theme presets (9) and lib items are not cataloged; no vendored previews.
