# UI SDK
> A library of behaviors to build your components.
- URL: https://ui-sdk.dev
- License: Free — live-previewable
- Stack: react, typescript, headless
- Install: `npm install @ui-sdk/react @ui-sdk/core`
- Notes: Apache-2.0 (github.com/vercel-labs/ui). BETA (cataloged at 0.1.0-beta.14) — expect breaking changes before 1.0. React 19 required (peer >=19). Headless and styling-agnostic. Core behaviors are documented as a group at ui-sdk.dev/docs/core/behaviors and are not cataloged as entries.
