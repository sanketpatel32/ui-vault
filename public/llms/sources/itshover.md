# Its Hover
> Animated icons that come alive on hover.
- URL: https://itshover.com
- License: Free — live-previewable
- Stack: react, typescript, tailwind, shadcn, motion
- Install: `npx shadcn@latest add https://itshover.com/r/<icon-name>.json`
- Notes: Apache-2.0 (github.com/itshover/itshover, default branch master) — vendor freely, keep the license notice. Icons animate on pointer hover only; they stay static on touch devices.
- Cataloged in UI Vault: 263 entries
