## Entries
- **Skeleton** https://skullet.lochie.me — Auto-skeleton wrapper: lays your real component out unseen while data is loading and draws a matching skeleton over it — a bar per text line, a block per image/control — so nothing shifts when content arrives. Pass data + sample (or loading), optional id to remember the shape; reveal transitions instant/crossfade/cascade. Draws in a shadow root with its own CSS (not Tailwind).
