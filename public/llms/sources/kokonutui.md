# Kokonut UI
> Free open-source React components for AI chat and agents.
- URL: https://kokonutui.com
- License: MIT — live-previewable
- Stack: react, nextjs, typescript, tailwind, motion
- Install: `npx shadcn@latest add @kokonutui/<name>`
- Notes: MIT (github.com/kokonut-labs/kokonutui). Free set only — the 10 items marked "Part of Kokonut UI Pro" and the Pro templates are paid and excluded. Registry is per-item (kokonutui.com/r/<name>.json; /r/index.json 404s) — the list comes from kokonutui.com/llms.txt. Catalog-only: no vendored previews yet.
- Cataloged in UI Vault: 116 entries
