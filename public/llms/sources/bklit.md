# Bklit UI
> Composable d3 + Motion chart components for React.
- URL: https://bklit.com
- License: MIT — live-previewable
- Stack: react, typescript, tailwind, d3, motion
- Install: `npx shadcn@latest add @bklit/<chart-name>`
- Notes: MIT (github.com/bklit/bklit-ui) for the chart components + registry; the Studio app carries a separate all-rights-reserved LICENSE-STUDIO.md and is not cataloged. Registry entries only — no vendored previews yet.
