# Amicro
> Open-source React micro-interactions and transitions powered by Motion.
- URL: https://amicro.vercel.app
- License: MIT — live-previewable
- Stack: react, typescript, tailwind, shadcn, motion
- Install: `npx shadcn@latest add https://raw.githubusercontent.com/Subhan-code/Amicro--Micro-transitions-/main/registry/ui/<name>.json`
- Notes: MIT (github.com/Subhan-code/Amicro--Micro-transitions-). Own CLI: npx @subhanhq/amicro@latest add <name>. The hosted @amicro registry at amicro.vercel.app rate-limits (429), so entries install from GitHub-raw URLs (hooks live under registry/hooks/). The 2 registry:lib utilities (presets, utils) are not cataloged.
- Cataloged in UI Vault: 174 entries
