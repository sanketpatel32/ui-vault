# editorcn
> Rich text editors for React, built on Tiptap with shadcn/ui tokens.
- URL: https://www.rtecn.space
- License: MIT — live-previewable
- Stack: react, typescript, tailwind, shadcn, tiptap, base-ui
- Install: `npx shadcn@latest add https://www.rtecn.space/r/<name>.json`
- Notes: MIT (github.com/shadcn-labs/editorcn). Prerequisite: Tiptap (@tiptap/* >=2.11.5 <4, pulled in as item dependencies). The @editorcn namespace (npx shadcn@latest add @editorcn/<name>) needs a components.json registries entry; the URL form works without config. The 8 icon-pack variants (Phosphor, Tabler, HugeIcons, Remix Icon for editor and block-editor) only overwrite icons.tsx and are not cataloged separately.
