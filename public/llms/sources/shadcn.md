# shadcn/ui
> The canonical copy-paste component collection you own outright.
- URL: https://ui.shadcn.com
- License: MIT — live-previewable
- Stack: react, typescript, tailwind, radix
- Install: `npx shadcn@latest add <component>`
- Notes: MIT (github.com/shadcn-ui/ui). v4 docs ship radix/base/aria variants of every component; the catalog carries the radix set. The @oidc namespace (ui.shadcn.com/oidc, same MIT repo) is cataloged as shadcn-oidc-* entries: npx shadcn@latest add @oidc/<name> (or register it first with npx shadcn@latest registry add @oidc=https://ui.shadcn.com/oidc/r/{name}.json); provider forms are family-granularity with 9 form-library variants each.
