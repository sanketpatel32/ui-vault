# snapcn
> shadcn-style video components for Remotion.
- URL: https://snapcn.dev
- License: MIT — live-previewable
- Stack: react, typescript, remotion
- Install: `npx shadcn@latest add @snapcn/<name>`
- Notes: MIT (github.com/shadcn-labs/snapcn). Prerequisite: an existing Remotion project (npx create-video@latest) — components render inside Remotion compositions, not as page UI. Free renders export at 720p with a small watermark; snapcn Pro ($179/yr or $279 once — 81+ components, 1080p, MCP) is excluded. The namespace is @snapcn (the old @snap-cn no longer resolves). Catalog-only: no previews (Remotion is not a hub dependency).
