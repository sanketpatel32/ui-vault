# Generative Loaders
> React loaders for generative UI.
- URL: https://generativeloaders.com
- License: MIT — live-previewable
- Stack: react, typescript, css
- Install: `npm install generative-loaders`
- Notes: MIT (github.com/kasturibuilds/generative-loaders; the npm repo field still points at the old kasturikhanke account). React >=18. Plain CSS — import "generative-loaders/styles.css" once. Young project (v0.1.1) — expect API churn. Entries are one per variant prop value.
