# Remocn
> shadcn/ui for video — MIT Remotion components you own.
- URL: https://remocn.dev
- License: MIT — live-previewable
- Stack: react, typescript, remotion, tailwind, motion
- Install: `npx shadcn@latest add @remocn/<name>`
- Notes: MIT (github.com/Remocn/remocn). Hard prerequisite: Remotion — every component renders video frames inside a Remotion composition, not interactive web UI. Cataloged from the official llms-components.txt index plus the icons gallery; no vendored previews (they need a Remotion player).
