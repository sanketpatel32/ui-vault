# Chat & AI (`chat`)

> Chat and AI conversation UI — bubbles, message streams, attachments. — group: Components

## Entries

- **Attachment** https://ui.shadcn.com/docs/components/attachment — Displays a file or image attachment with media, metadata, upload state, and actions. [MIT, live-previewable, category: chat]
- **Bubble** https://ui.shadcn.com/docs/components/bubble — Displays conversational content in a message bubble. Supports variants, alignment, grouping, reactions, and collapsible content. [MIT, live-previewable, category: chat]
- **Marker** https://ui.shadcn.com/docs/components/marker — Displays an inline status, system note, bordered row, or labeled separator in a conversation. [MIT, live-previewable, category: chat]
- **Message** https://ui.shadcn.com/docs/components/message — Displays a message in a conversation, with optional avatar, header, footer, and alignment. [MIT, live-previewable, category: chat]
- **Message Scroller** https://ui.shadcn.com/docs/components/message-scroller — A chat scroll container that anchors turns, opens saved transcripts, follows streamed responses, loads history without jumping, and jumps to any message. [MIT, live-previewable, category: chat]
- **Prompt Library** https://cult-ui.com/docs/components/prompt-library — Browse, insert, and manage prompt templates with categories and custom prompts. [MIT, live-previewable, category: chat]
- **AI Instructions** https://cult-ui.com/docs/components/ai-instructions — Manage and toggle AI instructions with a popover, search, and create-dialog. [MIT, live-previewable, category: chat]
- **AI Input Selector** https://kokonutui.com/docs/ai/ai-prompt — AI chat input with a model menu, a separate Effort control, file chips you can drop or paste, a / command menu, and Stop while replying. [MIT, live-previewable, category: chat]
- **AI Input Search** https://kokonutui.com/docs/ai/ai-input-search — AI composer with a Tools menu (browse, investigate, draft, run code, reason), a model picker and a live trace that stacks each source's avatar as it is read. [MIT, live-previewable, category: chat]
- **AI State Loading** https://kokonutui.com/docs/ai/ai-loading — Agent progress as a list of steps with a live log, elapsed time and a summary when done. [MIT, live-previewable, category: chat]
- **AI Text Loading** https://kokonutui.com/docs/ai/ai-text-loading — AI thinking text with a soft wave through the letters and words that swap letter by letter. [MIT, live-previewable, category: chat]
- **AI Voice** https://kokonutui.com/docs/ai/ai-voice — Voice input with a scrolling waveform, then a take you can play back, discard or send. [MIT, live-previewable, category: chat]
- **AI Tool Approval** https://kokonutui.com/docs/ai/ai-tool-approval — Approve or deny an agent's tool calls. Destructive calls need a press and hold, and decided calls fold into a trace with their output. [MIT, live-previewable, category: chat]
- **AI Tool Calls** https://kokonutui.com/docs/ai/ai-tool-calls — Tool calls inside a chat reply. Each call streams in as one row with a live timer, then they fold into a single line once the answer is ready. [MIT, live-previewable, category: chat]
- **AI Checkout** https://kokonutui.com/docs/ai/ai-checkout — An order the assistant puts together, paid without leaving the chat. The button fills while the charge runs, then the card folds into a one-line receipt. [MIT, live-previewable, category: chat]
- **AI Connect** https://kokonutui.com/docs/ai/ai-connect — A tool call that stops because an app is not connected. Connect it right in the message, and the call picks up where it stopped. [MIT, live-previewable, category: chat]
- **AI Send** https://kokonutui.com/docs/ai/ai-send — An email the assistant drafted, editable in place. Send starts a short countdown you can undo before anything goes out. [MIT, live-previewable, category: chat]
- **AI Schedule** https://kokonutui.com/docs/ai/ai-schedule — Meeting times the assistant found, each with a strip of both calendars so you can see why it is free. Booking folds the list into the event. [MIT, live-previewable, category: chat]
- **AI Attachment** https://kokonutui.com/docs/ai/ai-attachment — A file dropped into the chat uploads, then the assistant reads it page by page. Page citations in the answer light up the page they point at. [MIT, live-previewable, category: chat]
- **AI Code Run** https://kokonutui.com/docs/ai/ai-code-run — The assistant runs a short Python script in the reply. A marker steps down the lines, the output prints, and the chart it draws grows in. [MIT, live-previewable, category: chat]
- **AI Order Status** https://kokonutui.com/docs/ai/ai-order-status — A live delivery card in the reply. The courier moves along the route while the ETA counts down, and the route turns green on arrival. [MIT, live-previewable, category: chat]
- **AI Handoff** https://kokonutui.com/docs/ai/ai-handoff — The assistant hands the chat to a person, with what they will see so you don't repeat yourself. The queue counts down and the agent joins the thread. [MIT, live-previewable, category: chat]
- **AI Context Meter** https://kokonutui.com/docs/ai/ai-context-meter — How full the context window is, as a ring in the prompt footer that opens a breakdown by source and compacts when it fills. [MIT, live-previewable, category: chat]
- **AI Inline Citations** https://kokonutui.com/docs/ai/ai-citations — An answer with source chips beside each claim. One preview glides between chips and lights up the sentence it backs. [MIT, live-previewable, category: chat]
- **AI Diff Review** https://kokonutui.com/docs/ai/ai-diff-review — A coding agent's edits streaming in file by file, then reviewed per file with accept, reject and undo. [MIT, live-previewable, category: chat]
- **AI Model Selector** https://kokonutui.com/docs/ai/ai-model-selector — Pick a model and how hard it thinks. Effort is a detent track that reshapes for each model and keeps your level when you switch. [MIT, live-previewable, category: chat]
- **AI Token Alternatives** https://kokonutui.com/docs/ai/ai-token-alternatives — An answer where every unsure word shows what else the model weighed. Pick another word and the reply writes itself again from there. [MIT, live-previewable, category: chat]
- **AI Conversation Branches** https://kokonutui.com/docs/ai/ai-branches — A chat where editing a message starts a new branch. A small tree beside it shows every version, and you can jump between them. [MIT, live-previewable, category: chat]
- **AI Agent Lanes** https://kokonutui.com/docs/ai/ai-agent-lanes — A lead agent hands work to sub-agents that run side by side. Each gets a lane of tool calls, and you can scrub through the whole run. [MIT, live-previewable, category: chat]
- **AI Inline Edit** https://kokonutui.com/docs/ai/ai-inline-edit — Select text in a document and ask AI to rewrite it. The edit streams in place as a word-level diff you accept, discard or try again. [MIT, live-previewable, category: chat]
- **AI Message Queue** https://kokonutui.com/docs/ai/ai-message-queue — Keep typing while the agent works. Follow-ups stack above the composer, where you can reorder, edit or send one now, and go in one by one when the run ends. [MIT, live-previewable, category: chat]
- **AI Redact** https://kokonutui.com/docs/ai/ai-redact — Masks names, emails, card numbers and keys as placeholders before a prompt is sent, then fills the real values back into the reply. [MIT, live-previewable, category: chat]
- **AI Memory** https://kokonutui.com/docs/ai/ai-memory — An assistant that saves what it learns about you into a memory list. New facts replace the ones they contradict, and you can edit or forget any of them. [MIT, live-previewable, category: chat]
- **AI Autocomplete** https://kokonutui.com/docs/ai/ai-autocomplete — A text box that suggests how your sentence ends in grey after the caret. Tab takes it all, the right arrow takes one word, and typing the same letters keeps it. [MIT, live-previewable, category: chat]
- **Chat thread** https://uiarc.dev/components/chat-thread — A chat thread with grouped messages, reactions, read receipts, typing, and a composer with attachments. [MIT, live-previewable, category: chat]
- **Comment thread** https://uiarc.dev/components/comment-thread — Threaded comments with replies, reactions, mentions, inline edit, and resolve. [MIT, live-previewable, category: chat]
